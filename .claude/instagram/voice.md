# voice.md

Every skill in the Instagram pack reads this file. It lives in the repo at
`.claude/instagram/voice.md` so it survives between cloud sessions.

Fill it in by editing this file on GitHub (works fine on iPad), or send Claude
three of your own reels or captions and say "write my voice.md from these".
That works better than guessing at the answers.

This file matters more on Instagram than anywhere else, because you have to say
the words out loud. A line you would never say is not a draft, it is a retake.
